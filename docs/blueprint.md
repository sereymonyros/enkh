# **App Name**: enkh

## Core Features:

- Text Translation: Translate text from a textbox between English and Khmer using an AI-powered translation API.

## Style Guidelines:

- Primary color: Warm gold (#FFD700), reminiscent of Cambodian cultural heritage.
- Background color: Pale beige (#F5F5DC) to provide a neutral and calming backdrop.
- Accent color: Deep red (#A73300) to highlight important UI elements and actions.
- Body and headline font: 'PT Sans' for a clean and modern user experience.
- Use clean and simple icons with cultural references (e.g., Angkor Wat outline). The icons have a slight outline so that it can be adopted by a wider variety of cultural groups.
- Simple and intuitive layout with a clear separation between input and output fields. Consistent use of spacing and alignment.
- Subtle transition animations between translation states. A brief progress bar/spinner animation during translation.
